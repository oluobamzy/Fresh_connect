# Image & Icon Documentation for FreshConnect Frontend

## Logo
- **File:** `public/freshconnect-logo.svg`
- **Purpose:** Main logo for FreshConnect, used in the Header/Navbar (`src/components/Header.jsx`).
- **How to change:** Replace the SVG file in `public/` with your new logo, keeping the filename the same. The logo will update everywhere it is used.

## Icon/Asset Naming Convention
- Use descriptive names, e.g. `farmer-avatar.svg`, `cart-icon.svg`, `order-success.png`.
- Document each image/icon in this file with its purpose and where it is used in the codebase.

- ProductDetailCard.svg: Product detail placeholder image (Unsplash, documented in code)

## Fonts
- Google Fonts (e.g. Montserrat, Inter) will be imported in the main layout/theme for a modern look.
